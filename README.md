# Personal Portfolio

Source for [krishkapoor.com](https://krishkapoor.com) — personal site and portfolio.

Static site (HTML + Tailwind CDN), deployed via GitHub Pages with a custom domain (see `CNAME`).

## Structure

- `index.html` — the entire site
- `CNAME` — custom domain config for GitHub Pages
- `robots.txt` / `sitemap.xml` — SEO
- `DEPLOYMENT_GUIDE.md`, `SEO_IMPROVEMENTS.md` — notes on deploying and SEO tuning
